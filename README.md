# Олимпиады по информатике · 2026/27

Одностраничный сайт со всеми олимпиадами школьников из перечня Минобрнауки на 2026/27 учебный год, у которых есть профили по информатике и смежным направлениям (ИИ, информационная безопасность, робототехника, компьютерные науки).

## Что внутри

- `index.html` — весь сайт в одном файле (HTML + CSS + JS), без зависимостей и сборки.

## Возможности

- 26 олимпиад, 52 ИТ-профиля с уровнями перечня (I / II / III)
- Фильтры: поиск по названию, уровень, класс, тематика, статус
- Таймлайн этапов каждой олимпиады: регистрация → отборочный → финал
- Автоопределение текущего этапа и дедлайнов по сегодняшней дате
- Ссылки на официальные сайты и регламенты

## Запуск

Открыть `index.html` в браузере — этого достаточно. Либо через локальный сервер:

```
python -m http.server 8000
# → http://localhost:8000
```

## Как обновлять данные

Все данные лежат в массиве `OLY` в `<script>` внизу `index.html`. Формат записи:

```js
{
  n: 8,                    // № в перечне Минобрнауки
  name: '...',             // полное название
  short: '...',            // короткое имя
  lv: [1, 2],              // уровни ИТ-профилей
  tags: ['it','ai'],       // it, ai, sec, robot, eng, sport, misc
  cls: [7,8,9,10,11],      // классы
  site: 'https://...',     // официальный сайт
  docs: 'https://...',     // регламент/документы
  reg: ['2026-08-20','2026-09-21'],   // окно регистрации
  stages: [                // этапы
    {n:'Отборочный', s:'2026-09-25', e:'2026-10-11', f:'онлайн', a:0},
  ],
  profs: '...',            // строка с перечнем профилей
  note: '...',             // примечание (необязательно)
  apx: 1                   // все даты — оценка по прошлому сезону
                           // (rega: 1 — только окно регистрации оценочное)
}
```

Даты с `a: 1` / `apx: 1` показываются с пометкой «~оценка 25/26». Когда организатор публикует регламент сезона 2026/27 — замените даты на официальные и уберите флаг.

## Деплой на GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` публикует сайт при создании тега на основной ветке.

**Разовая настройка:** в репозитории Settings → Pages → Source → **GitHub Actions**.

**Релиз новой версии:**

```bash
git tag v1.0
git push origin v1.0
```

Actions сам соберёт и опубликует сайт; URL появится в выводе job и в разделе Environments → github-pages. Ручной запуск тоже доступен через Actions → Deploy to GitHub Pages → Run workflow.
